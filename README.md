# 自制三相无刷电调 ESC V1.0

本工作区和本对话负责单电机 ESC V1.0 的开发。项目基线由用户于 2026-10-26 提供，完整说明见 [ESC V1.0 项目说明](docs/ESC_V1.0_项目说明.md)。

## 本版范围

- 目标：完成能够独立驱动一台 T-MOTOR F1404 3800KV 电机的 ESC 验证板。
- 核心方案：STM32G071CBT6 + DRV8323SRTAR + 六颗 BSC026N04LS。
- 供电：GNB 3S 1100mAh 60C LiHV，满电 13.05V；TPS54202DDCR 为低压控制电路提供 3.3V。
- 控制：优先适配 AM32，采用无传感器六步换相，接收 DShot 指令。
- 首要目标：可靠、可调试、可复用。
- 后续用途：验证成功后复制四套 ESC，配合独立 STM32G431 飞控板。

## 建议推进顺序

1. 核对器件官方资料与 AM32 源码，明确 DRV8323S 的控制模式、反电动势检测路径、TIM1 换相输出、DShot 接收资源以及保护方式。
2. 建立 MCU 引脚和定时器、比较器、ADC、SPI 等资源分配表，再确定反馈电路和电流采样拓扑。
3. 完成各模块原理图与参数计算，确定外围 BOM。
4. 完成 PCB 布局布线及设计检查，输出生产文件。
5. 完成固件适配，依次执行基础上电、无桨空载和受控带载测试，记录电流、温升和故障处理结果。

当前预算：电池按用户最终更正的 66g；桨为 HQProp T3.5×2.2 双叶；PETG 机架暂按 60g。整机中心预算约 254g，设计计算点 260g，偏重情景检查到 320g。单 ESC 以 10A 持续、20A/10s 短时输入电流为设计目标，须实测确认；原 XT30 供电链路不按四路电流相加使用。

当前已形成 [第一版引脚分配表 A](docs/ESC_V1.0_引脚分配表.md)：沿用 G0_A 的六路桥臂和 PB4 DShot，SPI2 使用 PB13/PB14/PB15，保留 SWD 及反馈/采样资源。原生 PA9/PA10 布局需要关闭上游默认的 PA11/PA12 重映射。下一步按该表建立 MCU 最小系统与控制接口原理图，继续保留暂缓电路的资源。

具体工作顺序、资源约束及完成标准见 [下一步实施清单](docs/ESC_V1.0_下一步实施清单.md)。

2026-10-26 起聚焦 AM32 参考目标：根据用户明确的 STM32G071CBT6、128KB 规划要求，以 v2.21 的 `GEN_128K_G071` 为主参考，`GEN_64K_G071` 与 `AM32_ESC_G071` 仅作对照，详见 [目标推荐与存储说明](docs/AM32_参考目标推荐与存储说明.md)。128KB 链接、参数和 bootloader 布局作为移植任务统一核对。2026-10-27 用户授权本对话代选引脚，已形成分配表；反电动势电路、DRV 外围原理图及电流/电压采样详细设计继续暂缓。

后续实际核对已完成源码下载、参考目标编译与候选 128KB 链接布局检查，并找到匹配的 G071/PB4 128KB Bootloader 发布文件；详见 [GEN_128K_G071 核对结果](docs/GEN_128K_G071_核对结果.md)。尚未进行板级烧录或电机验证。V1 开发下载主路径建议采用 ST-LINK＋STM32CubeProgrammer＋下载后校验；单线升级保留为后续可选功能。
