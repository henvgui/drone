# ESC V1.0 电气指标与重量、电流预算

版本：初稿 A；日期：2026-10-26。

本轮完成电气指标第一步的工程预算，用于约束原理图和 PCB。重量未知项采用明确占位值；电流由推力需求和功率情景估算，不代表已测得目标桨的性能。10A/20A 是 ESC 设计与验收目标，尚非样机额定值。

## 1. 本轮输入与结论

- 电机：4 台 T-MOTOR F1404 3800KV，单台含原配线 9.34g。
- 电池：用户最终更正为 **66g**；型号维持 GNB 3S 1100mAh 60C LiHV。此前的 46g 已被更正，不参与本稿计算。
- 桨：HQProp T3.5×2.2 双叶，2 正 2 反，官方单只重量 1.1g。
- 机架：PETG；没有结构尺寸、STL 或切片重量，暂按 60g，并扫描 40～90g。
- 四块独立 ESC 加一块独立飞控，均计入整机；单电机验证板使用整机预算中的单通道指标。
- 不包含摄像头、图传、GPS、大型保护圈或任务载荷；15g 未分配余量不能视为这些设备均已覆盖。

结论：中心重量预算约 **254g**，设计计算点取 **260g**；现有假设组合约 220～314g，因此同时检查 300g 和 320g。初步保留 MCU、DRV8323S 和 BSC026N04LS；单 ESC 按 10A 持续、20A/10s 短时输入电流设计。原配 XT30 供电链路不能按四路额定电流相加使用。

数据依据：[F1404 官方规格](https://www.t-hobby.com/products/micro-fpv-drones-brushless-motor)、[GNB 官方规格](https://www.gaoneng.shop/products/gaoneng-gnb-lihv-3s-11.4v-1100mah-60c-xt30-lipo-battery-longrange)、[HQProp 官方规格](https://www.hqprop.com/hqprop-t35x22grey-2cw2ccw-poly-carbonate-p0359.html)。

### PCB 与线材的估算方法

ESC 先假设 40×35mm、成品厚 1.0mm、四层铜厚约 70/35/35/70µm，平均保留铜面积 60%。使用铜密度 8.96g/cm³、FR4 预算密度 1.85g/cm³，并将铜以外体积近似视为 FR4，得到裸板约 3.84g；元件和焊锡暂留 4.2g，合计约 8.04g/块。8g 是布局前估算；最终板厚、层叠、板框及储能电容改变时必须重算。这组尺寸和铜厚不是已冻结的 PCB 方案。

飞控暂按约 50×50mm 的小型已贴装板预留 12g，不含外部传感器载荷。

新增线材假设：主电源两根各 10cm 的 AWG16、四路 ESC 每路两根各 10cm 的 AWG20、另加总导体长度 0.8m 的 AWG28 信号线。按假设的绝缘外径与密度估算，线本体约 10.37g，再给机身侧插头和焊锡约 1.6g，取整为 12g。实际线规、长度和绝缘材质需在结构布局后替换。

PETG 中心预算相当于打印后净塑料体积约 48cm³×1.25g/cm³＝60g；没有切片结果时，不能把这个体积当作已知。不同配方密度有变化，例如厂商资料列出 1.25 或 1.3g/cm³。[PETG 材料资料](https://shop.polymaker.com/products/polylite-translucent-petg)、[另一 PETG 配方](https://shop.polymaker.com/products/petg)

## 3. 重量如何换算为电流

### 3.1 先确定推力需求

四轴悬停时，每台电机推力约为整机重量的四分之一；用 gf 表示推力时，260g 整机需要每台 65gf。

本稿把总推力/重量＝2 作为初步动力余量验收目标，因此 260g 时每台需达到 130gf，300g 时需 150gf，320g 时需 160gf。这是需求，尚未证明目标电机与桨在低电压下能达到它。推重比 2 也不意味着悬停油门正好 50%。

### 3.2 使用功率情景，而非直接用重量乘固定电流

理想悬停动量理论给出：

```
A = π(D/2)²
T = (m/4) × g × 推力倍数
Pideal = T^(3/2) / sqrt(2ρA)
Pmotor,input ≈ 1.15 × Pideal / ηeffective
I_ESC,input ≈ Pmotor,input / V
I_battery ≈ (4 × Pmotor,input + 1.5W) / V
```

其中 D＝0.0889m，单桨盘面积约 0.00621m²，ρ＝1.225kg/m³，g＝9.80665m/s²。15% 为安装干扰和模型余量，1.5W 为整机辅助电源预算。模型假设桨盘基本不重叠、接近海平面、静态悬停和较小机架遮挡；高海拔、大遮挡及实际桨效率变化均需重算。[NASA 推力与理想桨盘模型说明](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/propeller-thrust/)

ηeffective 定义为理想诱导功率/电输入功率，包含电机、ESC 及桨气动损失，不能与电机效率或前飞推进效率混为一谈。T-MOTOR 旧版官方测试中的一个参考点为 F1404 3800KV、GF3016、15.96V、158.01gf、输入 68.24W。按 3 英寸桨盘反算，ηeffective 约 0.267。该点的桨和电压均与本项目不同，仅用于量级检查。[官方旧版测试数据的检索入口](https://store.tmotor.com/product/f1404-fpv-motor.html)

本稿使用 ηeffective＝0.20～0.35 做偏保守至偏乐观情景扫描；这不是测量所得的效率区间，也不保证真实值位于其中。当前没有核实到 **F1404 3800KV＋HQProp T3.5×2.2＋3S** 的完整推力—电流曲线。

### 3.3 计算结果

下表采用 10.5V 带载预算电压，电流为单 ESC 的电池侧平均输入电流。全机值已加入 1.5W 辅助负载。

| 整机重量 | 工况/总推重比 | 单电机推力需求 | 单 ESC 输入电流情景 | 全机电池电流情景 |
| ---: | --- | ---: | ---: | ---: |
| 260g | 悬停/1 | 65gf | 1.3～2.3A | 5.3～9.2A |
| 260g | 推力余量/2 | 130gf | 3.7～6.4A | 14.8～25.7A |
| 300g | 悬停/1 | 75gf | 1.6～2.8A | 6.5～11.3A |
| 300g | 推力余量/2 | 150gf | 4.5～7.9A | 18.3～31.8A |
| 320g | 悬停/1 | 80gf | 1.8～3.1A | 7.2～12.5A |

因此，单 ESC 的 10A 持续目标覆盖了上述模型需求，并留有一定余量；不能据此推断满油门电流或最大推力。启动、堵转、突变负载以及相电流要另外约束。目标桨在满电 13.05V 的满油门电流仍需逐步测量。

## 5. MOSFET 与驱动器是否匹配

### 5.1 电池输入电流与功率桥电流分开核算

在单有源半桥 PWM、连续导通电流的简化情况下，可近似写成 I_DC≈D×I_loop，其中 D 是有效母线供能占空比，不等于油门百分比。电池侧平均电流 10A、D≈0.5 时，导通回路可能接近 20A；不能把 10A 直接代入所有 MOSFET 和电机线损耗计算。每相跨电周期 RMS、导通期间电流和瞬时峰值也不是同一个量。

### 5.2 BSC026N04LS

官方数据为 40V，25℃时最大导通电阻 2.6mΩ@10V / 3.6mΩ@4.5V，总栅极电荷最大 45nC@10V。这里将高温与栅压下降影响合并，暂以 **6mΩ/颗**作为热设计预算，不将其视为厂商全工况保证值。[Infineon 数据手册](https://www.infineon.com/dgdl/Infineon-BSC026N04LS-DataSheet-v02_03-EN.pdf?fileId=db3a3043410d6ee40141127f49e92b5d)

六步换相简化为两颗 MOSFET 构成导通回路：Pcond≈2×I_loop,RMS²×Rhot。再按满电 13.05V、24kHz、有效上升与下降时间合计 150ns、一个有源半桥中的两颗管均承担硬开关计算开关损耗上界情景；有效死区 200ns、二极管压降 1V，并给整桥增加 0.3W 杂散损耗余量。若最终调制同时硬切换多个桥臂，需增加开关损耗计数。

| 等效导通回路电流 | 整桥导通损耗 | 整桥开关损耗 | 含死区及杂散余量的整桥预算 |
| ---: | ---: | ---: | ---: |
| 10A | 1.20W | 0.47W | 2.07W |
| 15A | 2.70W | 0.70W | 3.85W |
| 20A | 4.80W | 0.94W | 6.23W |
| 30A | 10.80W | 1.41W | 12.80W |

这说明 MOSFET 的导通能力初步匹配，但相电流达到 20A 时，整板需要处理数瓦损耗，PCB 散热会成为关键。30A 不能当作持续运行点。表中还未计入外部线材与 PCB 铜损；0.3W 余量也不是对所有反向恢复和电容损耗的严格上界。

不使用数据手册 119A 直接宣称板级能力，也不把单器件特定试验板的热阻直接用于六颗共用小 PCB。外层 2oz、短回路、合适铜面和过孔应作为布局研究起点，最终需按温升核定。

### 5.3 DRV8323S

驱动器的栅极电流用于给 MOSFET 充放电，不承担电机的 10A 或 20A 主电流。其 6～60V 工作范围覆盖本项目；驱动能力重点看栅极电荷、开关频率和输出边沿。[TI 数据手册](https://www.ti.com/lit/ds/symlink/drv8323.pdf)

在 45nC 数据手册值之外，预留到每颗 **60nC** 的设计电荷预算。即使按三只高侧都在 24kHz 充电计算，平均高侧电荷需求约 4.32mA；48kHz 时约 8.64mA。六颗全按 24kHz 计算则合计约 8.64mA、栅极充电功率约 0.086W。这些需求低于 TI 在相应供电条件下列出的驱动电源电流量级，但具体栅压仍须在低输入电压下测量。

用最大 Miller 电荷 7.3nC 与 120/240mA 估算，Miller 区充/放电时间约 61ns/30ns，说明该驱动器具备驱动此 MOSFET 的量级条件。实际栅极电阻、回路电感和驱动电流变化尚未计入，不能将该值当成实测 VDS 边沿。

初步结论：保留 DRV8323S，无须因电机电流而换成更大“安培数”的栅极驱动器。

### 5.4 采样电阻

2mΩ 在有效值 10A/20A/30A 时分别耗散 0.2/0.8/1.8W。考虑温度降额，V1 优先给≥3W 封装留空间。实际单低边电阻中的 PWM 电流 RMS 必须依据回流拓扑计算，不等于电池平均值。

3.3V 参考、增益 20 时灵敏度幅值为 40mV/A。以 1.65V 为零点、输出约 0.25～3.05V 的理想线性范围估算，理论边界约±35A；留误差与零点余量后，本稿按±30A研究。输出方向与 AM32 电流换算需另行匹配，瞬态保护不能依赖这张理想量程表。

## 6. 电池、插头与线材的匹配

### 电池与主插头

标称能量约 11.4V×1.1Ah＝12.54Wh；按 60C 标称换算为 66A。这只是厂商额定值的算术换算，实际端电压、内阻和温升仍需测试，不能由此保证四通道任意电流组合。

常见 AMASS XT30U 官方页面给出 20A MAX，并附带 16AWG、温升条件；具体电池上的插头版本与尾线尚需核对。本文将≤15A作为初轮工程降额目标，并非厂家对整机的额定值。[AMASS XT30U 官方规格](https://www.china-amass.com/biao/268.html)

260g、推重比 2 的需求情景为全机 14.8～25.7A，已有一部分超出原插头边界；320g 时需求最高约 35A，更不能直接宣称匹配。悬停情景约 5～13A，则处于较低电流区间，仍需验收压降和温升。

因此原电池适合继续做单电机与整机低功率验证；若实测需要约 25～40A 的整机输出，应选定更高额定值的主连接器和尾线并更新预算。升级机身一侧插头不能自动解决电池内部引线或原配尾线的限制。四路 20A 短时能力相加为 80A，也超出本电池 60C 标称持续值，不能这样作为整机工作点。

### 线材损耗

按铜电阻率 0.017241Ω·mm²/m、温度系数 0.00393/K 估算，以下取导体 75℃，不包含接点电阻。电源线是正负回路长度之和；电机线为两根同时导通相线长度之和。

| 回路 | 合计导体长度 | 电流条件 | 估计损耗 |
| --- | ---: | ---: | ---: |
| AWG20，单 ESC 新增供电支线 | 0.20m | 10A DC | 0.81W |
| 同上 | 0.20m | 20A DC | 3.24W |
| AWG16，新增主供电线 | 0.20m | 20A DC | 1.28W |
| 同上 | 0.20m | 40A DC | 5.12W |
| 原配 AWG24，两根各 150mm 电机线 | 0.30m | 10A 导通回路 RMS | 3.07W |
| 同上 | 0.30m | 20A 导通回路 RMS | 12.27W |
| 若布置允许缩短至两根各 50mm | 0.10m | 10A 导通回路 RMS | 1.02W |

这不是载流量认证，但足以说明线长和相电流不能忽略。优先把 ESC 靠近电机、缩短相线，不能仅加粗 ESC 电池线就认为全链路已匹配。20A 短时目标也必须计入支线和原厂相线的温升。

## 7. 本步完成状态与后续验收

已完成：整机重量预算、推力需求、电流情景、单 ESC 初稿指标、MOSFET/驱动器量级校核、采样电阻功率修订建议以及整机插头限制识别。电气指标第一步作为“初稿 A”完成，可据此进入引脚与接口定义。

仍需实物闭合的三组输入：PETG 切片/成品重量与 PCB 最终重量；目标电机＋目标桨在 10.5/11.4/13.05V 的推力—电流曲线；原电池、插头、线材及 ESC 的压降和温升。

动力验收先检查 10.5V 时单电机能否达到 130gf（260g、推重比 2 的需求），并记录实际输入电流和相电流；如果整机最终接近 320g，则需求改为 160gf。测试若不能达到该点，或全机总电流超过供电边界，应调整重量、桨、电池链路或动力余量目标，不能用本模型宣布通过。

ESC 持续能力需在明确的环境、气流、线材和负载条件下测到热稳态；短时能力需验证初温、脉冲时间和恢复条件。验证板如扩大尺寸，必须更新重量再检查整机预算。
