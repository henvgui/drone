# 自制三相无刷电调 ESC V1.0 项目说明

> 本文保存用户于 2026-10-26 提供的项目需求基线。器件和参数的验证状态以正文为准；本文不代表已经完成电路、固件或实测验证。

## 一、项目名称

**基于 STM32G071 + DRV8323S 的三相无刷电机电子调速器设计**

项目版本：V1.0

控制方式：无传感器六步换相

目标电机：T-MOTOR F1404 3800KV

## 二、项目背景与目的

本项目的最终目标是设计并制作一架基于 STM32 的四轴无人机。

无人机计划使用四台 T-MOTOR F1404 3800KV 三相无刷电机。为了掌握完整的电机控制技术，同时减少对成品电调的依赖，决定自主设计 ESC 的硬件 PCB，并优先采用成熟的开源电调固件。

本阶段不直接制作完整无人机，而是先完成一块**能够独立驱动单台 F1404 电机的 ESC 验证板**。

### 主要目标

1. 掌握三相无刷电机的六步换相与无传感器控制原理。
2. 学习三相 MOSFET 功率桥、栅极驱动器及功率 PCB 设计。
3. 使用 STM32G071 实现电机启动、换相、调速与故障处理。
4. 研究和适配 AM32 开源电调固件，避免从零开发完整换相系统。
5. 实现 DShot 数字油门控制、SPI 驱动器配置、电流监测和基本保护。
6. 完成单电机带负载测试，验证电调的效率、温升和可靠性。
7. 将验证成功的设计复制为四套 ESC，最终应用于自制四轴无人机。

**本项目以实现可靠、可调试、可复用的电调为首要目标，不以最小体积、最低成本或 FOC 控制为第一阶段目标。**

## 四、电调总体硬件架构

电调主要由五个功能模块组成：

**1. 电源模块**

3S LiHV 电池输入，一路直接为三相功率桥与 DRV8323S 供电，另一路通过 Buck 降压为 STM32G071 提供 3.3V。

**2. MCU 控制模块**

使用 STM32G071CBT6，负责运行 AM32、生成换相控制信号、接收 DShot 指令、采集反馈数据以及与 DRV8323S 通信。

**3. 三相栅极驱动模块**

使用 DRV8323SRTAR，将 MCU 输出的控制信号转换为驱动六颗外部 N-MOSFET 的栅极信号，并提供驱动保护与电流采样放大功能。

**4. 三相 MOSFET 功率模块**

由六颗 BSC026N04LS 构成三组半桥，将直流电源转换为受控的三相输出 U、V、W，驱动 F1404 电机。

**5. 反馈与保护模块**

包含三相反电动势检测、低边电流采样、母线电压监测以及故障保护。

## 五、已选定的主要电子物料

| 器件 | 完整型号 | 单电调数量 | 立创编号 |
| --- | --- | --- | --- |
| 电调 MCU | STM32G071CBT6 | 1 | C432212 |
| 三相栅极驱动器 | DRV8323SRTAR | 1 | C701784 |
| N-MOSFET | BSC026N04LS | 6 | C3039672 |
| Buck 降压芯片 | TPS54202DDCR | 1 | C191884 |
| Buck 功率电感 | SRG0530-100-M，10µH | 1 | C53462978 |

### 核心器件的作用

**STM32G071CBT6**

- Cortex-M0+，最高 64MHz。
- 128KB Flash。
- 利用 TIM1 产生电机控制 PWM。
- 利用 ADC、比较器等资源获取电机反馈。
- 使用 SPI 配置 DRV8323S。
- 运行适配后的 AM32 固件。

**DRV8323SRTAR**

- 三相外置 MOSFET 栅极驱动器。
- 通过 SPI 调整驱动与保护参数。
- 提供三路电流采样放大器。
- 具备过流、欠压及栅极驱动故障保护功能。
- 本型号不集成额外的 Buck 降压模块。

**BSC026N04LS**

- 40V N 沟道功率 MOSFET。
- 单电调需要六颗。
- 组成 U、V、W 三相逆变桥。
- 采用约 5×6mm 功率封装。
- 最终温升与开关性能需要实测验证。

**TPS54202DDCR + SRG0530-100-M**

- 将 3S 电池电压降至 3.3V。
- 为 STM32G071 等低压控制电路供电。
- 电感量暂定 10µH。
- Buck 的电容、反馈网络与 PCB 布局仍需按照官方参考设计完成。

## 七、软件与控制方案

### 1. 开源固件

优先使用 **AM32**。

AM32 是运行在电调 MCU 上的开源无刷电机控制固件，不是硬件芯片。

第一版以无传感器六步换相为主，不开发 FOC。

### 2. 主要软件功能

- 接收 DShot 油门控制指令。
- 控制电机启动、加速、减速和停止。
- 利用反电动势估算换相时机。
- 输出三相 PWM 控制信号。
- 通过 SPI 初始化和配置 DRV8323S。
- 读取驱动器故障状态。
- 采集电流及电压数据。
- 实现必要的异常保护。

### 3. 软件适配工作

虽然 AM32 支持 STM32G071 平台，但我们的 PCB 采用自定义引脚分配，并搭配 DRV8323S，因此需要：

- 确定兼容的 AM32 硬件目标。
- 配置 TIM1 PWM 引脚及换相逻辑。
- 配置反电动势检测所需的反馈通道。
- 确定 DShot 接收引脚。
- 实现 DRV8323S 的 SPI 初始化与故障处理。
- 适配电流采样、保护和参数存储。

这些工作属于**将现有固件移植到自制硬件**，而不是从零编写整套六步换相算法。

## 八、第一版 ESC 的输入输出接口

| 接口 | 信号 | 说明 |
| --- | --- | --- |
| 动力输入 | VBAT+、GND | 接 3S LiHV 电池 |
| 控制输入 | DShot、GND | 由外部控制器发送油门 |
| 电机输出 | U、V、W | 接 F1404 三相线 |
| SWD | 3V3、GND、SWDIO、SWCLK、NRST | MCU 下载及调试 |
| 可选遥测 | 按固件配置 | 返回电机转速或状态 |
| 调试接口 | UART、测试点 | 用于开发阶段排查问题 |

第一版 ESC 板载独立 Buck，因此不需要由飞控额外提供 3.3V 供电。

## 九、开发阶段与验收目标

### 第一阶段：硬件与软件准备

完成原理图、PCB 布局、AM32 硬件适配方案及必要的接口设计。

### 第二阶段：基础上电验证

不接电机、不安装螺旋桨，在限流电源下检查：

- Buck 3.3V 输出是否正常。
- STM32G071 是否可以下载和调试。
- DRV8323S 的 SPI 是否通信正常。
- 驱动器是否有异常故障。
- 三相桥臂 PWM 及栅极信号是否正确。

### 第三阶段：电机空载运行

连接 F1404，不安装螺旋桨，验证：

- 电机能够可靠启动。
- 无传感器六步换相正常。
- DShot 能控制电机输出。
- 加减速平稳，无明显失步。
- 异常停止和基本保护有效。

### 第四阶段：带负载测试

将电机可靠固定于测试台，安装适配桨叶并做好防护，逐步测试：

- 不同油门下的电流和功耗。
- MOSFET 与驱动器温升。
- 电源母线纹波及电压尖峰。
- 启动可靠性与负载变化响应。
- 长时间运行稳定性和保护功能。

## 十、项目最终成果

第一阶段预计产出：

1. 一套完整的单电机 ESC 原理图。
2. 一块自主设计的 ESC PCB。
3. 对应的元器件 BOM 和 PCB 生产文件。
4. 一套能够运行的、适配后的 AM32 电调固件。
5. F1404 电机启动、调速、电流、温升和保护测试记录。

单电调成功后，再制作四套相同的 ESC，配合独立的 STM32G431 飞控板，构建完整四轴无人机。

**项目的核心成果不只是让一台电机转动，而是掌握并验证一套能够实际用于无人机的三相无刷电机驱动系统。**
