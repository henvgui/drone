## 2. 首轮硬件判断

总体方案适合以可靠、可调试为优先的单电机验证板，目前没有要求推翻核心选型的依据。以下判断仍需在详细设计阶段闭合。

- STM32G071CBT6：适合继续使用。AM32 官方列出 G071 支持，芯片具备高级定时器和比较器等资源。MCU 型号支持不等于任意引脚布局均可直接运行现成固件。
- DRV8323SRTAR：适合继续使用。支持 3.3V 逻辑及 6x PWM，工作供电范围覆盖 3S。建议优先研究 6x PWM 路径，并核对输出极性、悬空状态、死区、ENABLE 和 nFAULT。S 型 SPI 配置及故障处理需落实；同系列 H 型的硬件配置不能直接代替。
- BSC026N04LS：40V、低导通电阻的方向合理。官方列出最大导通电阻 2.6mΩ（VGS=10V），总栅极电荷典型 32nC（10V）。还需按实际栅压、PWM、温度和布局校核驱动电流与损耗。器件的额定电流不能直接作为整板额定电流。
- TPS54202DDCR：4.5～28V 输入、2A 输出，适合将 3S 降到 3.3V。需要完成真实低压负载预算、反馈及滤波设计，并把母线瞬态纳入输入耐压校核；Buck 的输入耐压比 MOSFET 低。
- SRG0530-100-M：10µH 可保留为候选。供货页面所附数据表列出饱和电流典型 3.5A、温升电流典型 3A，不能将这些典型值视为全温度保证值。需按 Buck 峰值电流、容差和故障工况校核。按理想连续导通估算，13.05V 输入、3.3V 输出、500kHz、10µH 时电感纹波约 0.49A 峰峰值；实际轻载可能处于跳脉冲模式，不能直接套用这一波形。
- 2mΩ、≥2W 采样电阻：数值方向合理，尚不能定稿。假设流过电阻的有效值电流为 10A 或 20A，则损耗分别为 0.2W、0.8W，压降幅值分别为 20mV、40mV。还需校核脉冲、温度降额、Kelvin 走线以及放大器/ADC 量程。
- F1404 3800KV + 3S：官方电机规格列出 3～4S，电压搭配方向合理。官网同时列出 19A 的 60s 峰值电流；这不是本项目 3S + 3.5 英寸桨组合的实测数据，也不是连续额定电流。3.5 英寸低桨距双叶仍需具体型号和电流、推力测试。

## 3. 两项关键兼容性问题

### 反电动势检测

当日读取的 AM32 G071 comparator.c 按换相步骤切换比较器输入，用于检测悬空相。原理图需要明确三相分压、比较参考、滤波、输入保护、比较器引脚和极性。仅给 U/V/W 各接一个普通 ADC 输入，不能据此认定符合当前固件的换相反馈路径。

DRV8323S 提供栅极驱动和电流放大功能，不会自动替 MCU 完成该反电动势检测路径。

### 电流采样与转换

DRV8323 官方数据表允许使用一个放大器检测三桥臂电流之和，因此单低边采样在芯片能力上可行，并非必须使用三颗电阻。但需确定采样电阻、功率回流和母线电容的相对位置、SP/SN 接法以及未使用放大器的处理方式；母线电流采样不能无条件当作完整相电流。

AM32 Src/main.c 当日版本通过 ADC 电压减 CURRENT_OFFSET，再除以 MILLIVOLT_PER_AMP 计算电流，并将负结果截为零。DRV8323 数据表给出的电流转换式包含参考电压及输出极性，因此必须核对接法下的电流方向、零点和增益，不能只修改采样电阻常数。还需验证 PWM 采样时刻、滤波及测量结果所代表的电流。

硬件快速故障保护、固件限流和电流遥测应分别验证，不能用低速 ADC 平均值替代全部过流保护。

## 4. 下一步与完成标志

下一步先完成硬件与 AM32 接口定义，再进入各模块原理图设计。

1. 定义电气和热目标：连续电流、短时电流及持续时间、允许温升、最低工作电压和保护行为；约 20A 短时工况应纳入初步预算，不能据此宣称整板已具备 20A 能力。启动及堵转另行校核。
2. 选择并记录 AM32 版本/提交及 G071 参考 target，核对 bootloader、Flash 布局和 DShot 输入资源。
3. 建立引脚资源表：六路桥臂输入、比较器三相反馈及参考、DShot 定时器/DMA、SPI、ENABLE、nFAULT、电流/母线 ADC、SWD、调试接口。
4. 画出反电动势与电流采样电路，确定固件参数与需修改的逻辑，核对所有信号冲突。
5. 完成其余原理图及计算：MCU 最小系统、Buck、驱动供电/电荷泵、栅极外围、三相功率桥、母线电容、保护和测试点。

本轮近期完成标志：接口与引脚表、首版电气指标表、采样拓扑及 AM32 修改清单均可供审查，主要兼容性问题已有明确实现路径。之后再完成原理图审查和 PCB。
