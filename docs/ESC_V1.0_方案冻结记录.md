## XT30 的采用边界

V1.0 是单电机验证板。其 10A 持续输入电流目标低于常见 AMASS XT30U 官方页面所列的 20A MAX，因此可以保留 XT30 继续设计；20A/10s 是待验证的 ESC 短时能力目标，不能用接口额定值直接证明整条电源链路通过。

厂商额定值附有 16AWG、温升条件，不能理解为任何线径、接头版本及安装状态下均可无条件长期承载 20A。[AMASS XT30U 官方规格](https://www.china-amass.com/biao/268.html)

后续四轴共用电池时，主 XT30 承担四路总电流。260g 的悬停需求情景约 5.3～9.2A，推重比 2 的需求情景约 14.8～25.7A，后者已跨过该额定边界。因此整机是否保留同一主接口，应由实测总电流、压降与温升决定，当前不把超过 20A 的整机工作点纳入已确认能力。≤15A 的初轮总电流降额建议保留；它是试验预算，不是厂商额定值，也不是已经实现的整机限流功能。

## 尚需设计与验证的内容

电源架构和主器件可作为基线，但 Buck 的电感、电容、反馈、输入瞬态抑制和 PCB 回路尚未定稿；10µH 电感继续作为候选。栅极外围、采样拓扑、保护参数、MCU 引脚和 PCB 结构也尚未冻结。

电源实际验收至少需要完成：3S 输入范围内的 3.3V 稳态/负载变化检查；电机运行时的母线与 3.3V 纹波、尖峰和 MCU 复位检查；目标电流下电池、插头、线材及 ESC 温升检查。验收参数沿用电气指标初稿，不在没有样机数据时宣称已经通过。

下一步：按上述基线确定 AM32 参考目标及 MCU 引脚资源表，再完成各模块原理图与外围参数。发现明确的不兼容或实测不足时，记录证据后调整对应设计项。
